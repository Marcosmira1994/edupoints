# EduPoints UI — componentes (papéis inspirados em templates gamer; visual e textos próprios)
Button (.btn) — pílula; Oxanium 700; hover com brilho; active desce 1px; foco: anel 2px ciano. Real <button>.
Input (.inp) — raio 12, borda 3.6:1 (#6a6a8e), foco com anel ciano suave. Sempre com <label>.
Card (.ui-card) — superfície #12121c, hairline #2c2c44, hover: borda ciano + brilho leve. Aura/EX NÃO usam (identidade própria).
Pill (.ui-pill ok|warn|off|bad) — status com ponto + texto (nunca só cor). Ex.: Ativo, Pendente, Concluída.
Chip (.ui-chip) — rótulo + valor em negrito (ex.: "Nível 3", "120 XP").
Icon button (.ui-icon-btn) — 40px circular, hover preenche com acento; exige aria-label.
Progress (.ui-bar) — barra 8px com gradiente ciano→lima; sempre com texto numérico ao lado.
Eyebrow (.ui-eyebrow) — sobretítulo em caixa-alta espaçada.
Movimento: respeita prefers-reduced-motion. Contraste: 19 pares, 0 falhas AA (ver tokens.json).
